# Memory Match

A small, responsive memory matching game built with HTML, CSS, and vanilla JavaScript. No dependencies or build step are required.

## Play

Open `index.html` in a web browser. Flip two cards at a time and find all eight matching pairs. The game tracks your moves and elapsed time. Select **New game** to shuffle the cards and start over.

## Project files

- `index.html` — page structure and game board
- `style.css` — responsive layout, card flip animations, and visual styling
- `game.js` — card shuffling, matching rules, move counter, and timer

## Run locally

You can open `index.html` directly in your browser. Alternatively, serve the project folder using any local static web server.
